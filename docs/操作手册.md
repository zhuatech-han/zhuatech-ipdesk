# IPDesk 操作手册

## 初始配置

管理员从本机私有环境文件获取首次密码，创建内部部门及外部代理部门，再建立账号。内部部门采用内部角色，代理部门只能采用代理角色。邮箱为单个有效地址；需要邮件提醒时单独勾选订阅。已建立账号不更换所属部门，组织变动通过停用旧账号、新建正确范围账号处理。

默认角色：平台管理员（全部范围）、提案人（本人案件）、案件经办（本部门）、知识产权复核（本部门）、财务经办、财务复核（本部门）、外部代理（仅当前分派）。管理员可维护角色权限，但代理角色不能获得内部管理或财务权限。账号或部门停用立即影响现有会话和文件下载。

## 提案与案件

1. 提案人填写专利、商标或著作权草稿，保存后提交；待审时提交者可撤回。
2. 知识产权复核人员填写意见，批准或退回；提案创建者及提交者不能审批自己提案。
3. 经办人员从获批提案建立唯一案件，补充申请人、法域、申请号、申请日期等人工资料。
4. 分派本部门负责人和外部代理。外部代理仅看当前分派案件，撤换后旧会话立即失去案件、共享文件和提醒访问。

## 文件与期限

文件仅接受实际 PDF、PNG、JPEG，不能只改扩展名；PDF 中的脚本、表单和嵌入对象会被拒绝。每份最多3 MiB；同名文件追加版本，不覆盖历史。内部经办可选择共享，代理上传始终共享。财务上传的内部凭据不会自动共享。

登记期限必须选来源文件、字典类型、日期和负责人，先进入“待复核”。外部代理负责的期限必须使用共享来源文件。待复核项对代理隐藏。独立复核后才成为执行期限。

修改已批准期限使用“新版本”，旧版本继续有效并继续提醒，直到新版本获批后旧版本才变为“已替换”。有待审替换时不能提前完成旧版本。拒绝新版本保留旧版本。

责任人上传交付证明，再提交完成；复核人员可验收或退回。取消也需要提出原因和独立复核。待验收和待取消仍属于未结束任务，继续提醒并阻止结案。

## 费用与线下支付凭据

财务经办登记费用类别、收款方、业务引用、金额和证明，提交后另一位财务复核人员审批。金额采用整数分，页面显示元。案件权限不等于财务权限，普通案件人员与代理看不到费用。

实际在线下付款后再登记凭据，不通过系统发起转账。待审付款占用费用可用额度，防止多人重复登记；审批独立进行。错误凭据采用原整笔冲销，冲销待审期间不释放余额；冲销批准后才恢复可登记余额。同一付款不能重复冲销。

## 结案与重开

尚有未完成期限、待审／草稿费用、未付清获批费用或待审付款时不能结案。经办发起结案，另一位有权限的人批准；结案后禁止新增文件和修改业务。重开也通过发起和独立复核，原文件和审计保留。

## 提醒配置与处理

管理员设置 `reminders_enabled`、提前天数 `warning_days`、`email_enabled`；实际 SMTP 连接在服务器环境配置。默认仅站内提醒。负责人与内部案件负责人在其当前可见范围内接收；不自动发给全部管理员或全部代理。

调度器每60秒扫描，管理员也可“立即检查”。同一任务版本、日期、接收者和渠道去重。处理完成、账号停用、代理撤换、邮箱更改时，投递前再次核对，失效提醒跳过。

投递状态：NEW为站内未读，READ为站内人工已读；PENDING待投递，SENDING已持久化认领，SENT表示 SMTP 接受，SKIPPED表示不满足配置或资格，UNKNOWN表示异常或超时无法确定。不会把异常自动重试为成功。管理员核对邮件服务器并确认未送达后，可人工重试UNKNOWN/SKIPPED，最多3次；SENT不代表对方收件箱到达。

## 审计与常见问题

业务动作保存操作者、对象、结果和意见，不记录密码和文件内容。发生409说明版本已变化，应刷新后核对再操作。404也可能表示当前账号无范围权限，不意味着案件不存在。权限由服务端逐次核对，隐藏菜单不构成安全边界。

报表和CSV遵守当前账号范围。文件下载需登录并再次核对当前案件与共享权限。日期为人工日期，机构时区 Asia/Shanghai；不根据外部法规自动推算。
