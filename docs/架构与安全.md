# IPDesk 架构与安全

## 分层

Vue 3负责交互，Nginx同源代理`/api`和健康接口，Spring Security保护会话、CSRF和接口。Access统一判断部门、角色、案件和代理范围；Workflow执行状态机；Files校验原始文件；Notifications持久化通知并通过JavaMail发送；Catalog控制管理字段白名单。MySQL是持久化来源，Flyway V1初始化；Hibernate只校验结构。

数据表包括组织与账号、角色、字典、参数、菜单、提案、案件、文件版本、期限、费用、付款凭据、通知、审计及互斥行。文件内容存longblob，摘要存SHA-256，备份含原始文件。所有业务外键在数据库约束。金额按整数分存BIGINT，JSON以字符串传输，前端使用BigInt，避免浮点舍入。

## 状态机

提案：DRAFT／REJECTED → PENDING → APPROVED／REJECTED；提交者可撤回待审提案。一个获批提案最多一案。

期限：PENDING → OPEN／REJECTED；OPEN → DONE_PENDING → DONE／OPEN；OPEN → CANCEL_PENDING → CANCELLED／OPEN。替换新版本获批后旧版本才SUPERSEDED。日期与来源由人录入并独立复核。

费用：DRAFT／REJECTED → PENDING → APPROVED／REJECTED。付款：PENDING → APPROVED／REJECTED。冲销为独立负金额记录，不修改已批准原凭据。

案件：ACTIVE → CLOSING → CLOSED／ACTIVE；CLOSED → REOPENING → ACTIVE／CLOSED。未完成任务、未审财务或未付清费用阻止结案。

## 访问与并发

内部权限包含全部、部门、负责人／创建者范围；外部代理仅当前分派案件和本人任务，且不允许内部权限升级。明细、列表、下载、导出和通知均再次检查范围；内部案件权限不自动含财务权限。

账号停用、部门停用、角色变化和密码变化按请求生效。密码BCrypt，长度12–72个UTF-8字节，大小写和数字；无公开注册。HttpOnly/SameSite=Strict会话，30分钟空闲，登录旋转会话与CSRF令牌。进程内8次失败／5分钟限流，重启会清空；生产应再增加网关限流和监控。未实现MFA、SSO、独立租户或防病毒引擎。

业务写入先锁数据库互斥行以保持费用预占与版本变更原子性，实体另有乐观版本；代价为写吞吐受限。列表读取上限10,000条，超过时明确拒绝；适配大规模数据需改为数据库分页与聚合。概览期限最多显示100条。

## 通知事务

入队、认领和结果更新分别在明确事务中完成，发送SMTP在事务外进行。认领状态先提交，崩溃后超过120秒仍SENDING转UNKNOWN。投递前再次检查人员、案件、任务、渠道订阅与邮箱；唯一键防同日重复入队。异常不记录服务器密码或邮件原文，也不盲目自动重试。

这不提供跨SMTP与数据库的严格一次投递：SMTP已接受但响应丢失时仍可能UNKNOWN。必须人工核查再决定重试。系统SENT只证明SMTP接受。

## 文件与部署边界

每文件3 MiB，PNG/JPEG真实解码、像素数上限2000万；PDF最多200页，对脚本、表单、嵌入内容等静态拒绝。没有恶意软件查杀保证，推荐生产再接入隔离扫描和受控下载。文件仅附件下载，no-store；HTML、Office与压缩包不接受。每案最多100个文件版本与默认40 MiB总量（可10–100 MiB）。

默认回环绑定，不公开数据库。生产要求HTTPS、Secure Cookie、受控SMTP与MySQL TLS校验、备份和恢复演练。默认MySQL TLS REQUIRED只加密，生产应配置CA与VERIFY_IDENTITY核对身份。没有进行渗透测试、规模负载或长时间生产验证。
