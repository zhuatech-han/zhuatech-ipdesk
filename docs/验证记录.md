## SMTP 捕获复现

另存以下测试覆盖文件于仓库外，用全新独立实例，设置`SCHEDULER_ENABLED=false`避免测试时后台扫描：

```yaml
services:
  backend:
    environment:
      SCHEDULER_ENABLED: 'false'
      MAIL_ENABLED: 'true'
      MAIL_HOST: mailpit
      MAIL_PORT: '1025'
      MAIL_FROM: ipdesk@example.invalid
      MAIL_TLS: 'false'
    depends_on:
      mailpit: {condition: service_started}
  mailpit:
    image: axllent/mailpit:v1.31.6
    ports: ['127.0.0.1:18176:8025']
```

```bash
docker compose -f compose.yaml -f /absolute/private/mail-test.yaml -p ipdesk-test up --build -d --wait --wait-timeout 900
python3 scripts/smoke.py --env-file .env --private-state /tmp/ipdesk-test-state.json --mailpit-url http://127.0.0.1:18176
```

仅在本机捕获服务中关闭TLS，真实SMTP保持STARTTLS及证书验证。私有状态文件、数据库转储、真实配置均不能发布。云端工作流默认验证未配置SMTP的明确跳过分支，本机额外验证实际SMTP接受与捕获内容。
