# IPDesk 部署、备份与恢复

## 环境与上线

Docker Compose默认三服务，MySQL 8.4、Java21运行时、Nginx；仅前端127.0.0.1:8176暴露。启动命令见[README](../README.md)。生产置于受控HTTPS反向代理之后，设置`COOKIE_SECURE=true`，控制访问范围；实际数据库、SMTP密钥仅保存在私有环境文件或受控密钥设施，不提交Git。先取得商业授权。

首次构建会执行后端测试，不能通过跳过测试发布。Flyway启动时迁移，Hibernate验证结构；失败应读取选定实例日志，修正版本／配置后复测，不能清库或改已有迁移校验值。

默认卷`<project>_mysql-data`包含数据库和文件原文。可选择`compose.storage.yaml`的显式本地目录，先创建全新的专用目录，再设置`MYSQL_DATA_DIR`为绝对路径：

```bash
docker compose -f compose.yaml -f compose.storage.yaml -p ipdesk config --quiet
docker compose -f compose.yaml -f compose.storage.yaml -p ipdesk up --build -d --wait --wait-timeout 900
```

该选项不会自动搬迁旧卷数据；不要将现有数据目录、其他项目目录或空的错误挂载点当成迁移目标。移动硬盘必须保持原卷名、已挂载、可写且有足够容量。更换路径前先备份并在独立空实例恢复验证。

## 邮件

默认`MAIL_ENABLED=false`，仅站内。填写真实SMTP主机、端口、用户名、密码、发信地址；默认587与必需STARTTLS。管理端开启`email_enabled`，账号填写邮箱并勾选订阅，总提醒开关需开启。服务管理接口只返回邮件是否配置，不显示秘密。使用指定测试邮箱验收后再启用真实通知。此版本不支持隐式SMTPS465、短信、微信或送达回执。

## 私有备份

下面命令只针对显式`ipdesk`实例，备份路径必须在仓库外且不能已存在：

```bash
python3 scripts/backup.py --env-file .env --project ipdesk --output /absolute/private/ipdesk-backup.sql
```

脚本以单事务导出、包含二进制文件原文，输出权限600。备份属于敏感业务数据，需加密保管、限定访问和保留周期；不进入源码或公开截图。并非在线主从复制或增量备份。

## 独立空库恢复演练

先创建另外的私有环境文件，使用独立密码与不同WEB_PORT，例如8177。启动`ipdesk-restore-check`的MySQL，确认目标没有业务数据：

```bash
docker compose --env-file /absolute/private/restore.env -p ipdesk-restore-check up -d --wait --wait-timeout 900 mysql
python3 scripts/restore.py --env-file /absolute/private/restore.env --project ipdesk-restore-check --input /absolute/private/ipdesk-backup.sql
docker compose --env-file /absolute/private/restore.env -p ipdesk-restore-check up --build -d --wait --wait-timeout 900
```

恢复脚本只接受`ipdesk-restore-*`实例、私有环境文件、权限600备份，非空数据库直接拒绝；不允许覆盖原业务库。随后验证健康、登录、案件／版本／审批／金额、审计及文件下载SHA-256一致。导入后保留源库账号密码，初始ADMIN_PASSWORD不重置它们。演练结束只删除该次独立测试实例与卷。

## 运维与故障

- `docker compose -p ipdesk ps`检查健康；`logs --tail 100 backend`只在受控终端查看，避免公开输出。
- 数据库初始化可能较慢，尤其外置磁盘；先查磁盘挂载和日志，不恢复Docker出厂设置。
- SMTP失败或发送进程中断会留下SKIPPED／UNKNOWN，人工核对服务器后再明确重试；不要把SENT当作收件人已阅。
- 应维护最少两位独立审批人员；管理员不绕过自审限制。
- 容量、并发、漏洞评估、外部文件扫描、容灾与监控需按实际部署补充；本学习版未提供生产SLA。
